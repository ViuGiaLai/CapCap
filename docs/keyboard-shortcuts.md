# Bảng Tra cứu Phím tắt (Keyboard Shortcuts)

VIUStudio hỗ trợ đầy đủ các tổ hợp phím tắt chuẩn công nghiệp (tương tự Premiere Pro, CapCut, DaVinci Resolve) giúp tăng tốc độ biên tập trên Timeline.

---

## Điều hướng & Phát Video

| Phím tắt | Thao tác thực hiện |
| :--- | :--- |
| `Space` | Bật / Dừng phát video (Play / Pause) |
| `J` | Tua lùi video (Rewind 2x, 4x) |
| `K` | Tạm dừng phát video (Pause) |
| `L` | Tua tiến video (Fast Forward 2x, 4x) |
| `Left Arrow` (←) | Lùi 1 khung hình (Previous Frame) |
| `Right Arrow` (→) | Tiến 1 khung hình (Next Frame) |
| `Shift + Left Arrow` | Lùi 1 giây trên Timeline |
| `Shift + Right Arrow` | Tiến 1 giây trên Timeline |
| `Home` | Nhảy về đầu Timeline (00:00:00) |
| `End` | Nhảy đến cuối video |

---

## Thao tác Cắt ghép trên Timeline

| Phím tắt | Thao tác thực hiện |
| :--- | :--- |
| `S` | Cắt (Split) clip/phụ đề tại vị trí con trỏ playhead |
| `Delete` / `Backspace` | Xóa clip hoặc đối tượng đang chọn |
| `Ctrl + Z` | Hoàn tác thao tác trước đó (Undo) |
| `Ctrl + Shift + Z` / `Ctrl + Y` | Làm lại thao tác (Redo) |
| `Ctrl + +` (hoặc cuộn chuột lên) | Phóng to Timeline (Zoom In) |
| `Ctrl + -` (hoặc cuộn chuột xuống) | Thu nhỏ Timeline (Zoom Out) |
| `Ctrl + 0` | Khớp toàn bộ Timeline vào màn hình (Fit Timeline) |

---

## Quản lý Dự án & Xuất bản

| Phím tắt | Thao tác thực hiện |
| :--- | :--- |
| `Ctrl + N` | Mở hộp thoại tạo dự án mới |
| `Ctrl + O` | Mở dự án đã lưu |
| `Ctrl + S` | Lưu trạng thái dự án hiện tại |
| `Ctrl + E` | Mở bảng xuất bản video (Export) |
| `F5` | Chạy Fast Preview (Xem trước 5 giây) |
